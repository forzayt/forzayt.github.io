Self-Host Ant Media Server on Ubuntu (Locally)

Share This Post
  • Facebook
  • Twitter

If you're looking to run your own live streaming platform like YouTube Live or Twitch, Ant Media Server is one of the best self-hosted options. In this blog post, I'll guide you step-by-step on how to install and run Ant Media Server (Community Edition) on your Ubuntu machine locally. For the official quick start guide, visit Ant Media Server Documentation.

📌 What is Ant Media Server?

  • 📡 WebRTC (ultra-low latency)

  • 🎥 RTMP, HLS, and DASH

  • 🧠 Recording, Transcoding, Adaptive Bitrate (Pro)

  • 🤝 Scalable with clustering

🧰 Prerequisites

  • Ubuntu 20.04 or 22.04 (64-bit)

  • 4 GB RAM or more

  • Java 8 (OpenJDK)

  • Basic terminal skills

📦 Step 1: Update Your System 

sudo apt update && sudo apt upgrade -y

☕ Step 2: Install Java 8 

sudo apt install openjdk-8-jdk -y

Verify Java installation:

java -version

Expected output: openjdk version "1.8.x"


📥 Step 3: Download Ant Media

Download from the ANT MEDIA OFFICAL WEBISTE or use: 

wget https://github.com/ant-media/Ant-Media-Server/releases/download/ams-v2.8.2/ant-media-server-community-2.8.2.zip

📂 Step 4: Unzip the File

Install unzip:

sudo apt install unzip -y

Unzip the downloaded file:

unzip ant-media-server-community-2.8.2.zip

Change directory:

cd ant-media-server

▶️ Step 5: Start the Server 

./start.sh

You should see: Ant Media Server is started.

🌐 Step 6: Access the Web Dashboard

Open your browser and go to: 

http://localhost:5080

Login:

  • Username: Admin

  • Password: Admin
🧪 Step 7: Test a Stream

  1. Go to the Applications tab

  2. Choose LiveApp

  3. Use OBS or browser webcam to test

OBS RTMP settings: 

rtmp://localhost/LiveApp/stream1

🌍 Step 8: Access From Another Device 

hostname -I

Use the IP you get, for example: 

http://192.168.1.42:5080

⚠️ Make sure port 5080 is not blocked by UFW or firewall.

✅ Conclusion

You now have a local, self-hosted Ant Media Server running on Ubuntu! Use it to:

  • Build your own YouTube/Twitch-style service

  • Experiment with WebRTC/RTMP/HLS

  • Learn streaming technology hands-on
